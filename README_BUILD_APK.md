## How to Compile into an Installable .APK
1. **On Android Phone (Zero PC Required):** Upload this repository to GitHub. The included workflow `.github/workflows/build-apk.yml` automatically runs `gradle assembleDebug`, signs the APK, verifies it with `apksigner`, and publishes the installable `.apk` under GitHub Actions Artifacts.
2. **On Desktop (Android Studio):** Open this folder in Android Studio and select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
