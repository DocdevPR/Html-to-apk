Conversion Mode Selection (Mode A vs Mode B)

Choose whether your Android APK packages local offline HTML/CSS/JS assets or wraps a live remote HTTPS website.

Mode A • Standalone Offline Ready

Local HTML Application

Packages all HTML, CSS, JavaScript, images, and fonts into `app/src/main/assets/www/` and serves them securely via AndroidX `WebViewAssetLoader` (`https://appassets.androidplatform.net/assets/www/index.html`). Works 100% offline with full relative path support.

  • Loads local `index.html` securely without `file://` CORS blocks
  • Full offline capability & relative path preservation
  • Native Android back navigation & file download listener
Mode B • Live Remote URL

Website Wrapper Application

Generates a native Android WebView wrapper around a remote website URL with pull-to-refresh, custom offline fallback screen, native back stack handling, and external browser routing.

HTTPS URL verified.
Important Technical Disclosure:

1. Wrapping a remote URL does not convert a live website into a standalone offline app unless its HTML/CSS/JS assets are locally imported under Mode A.

Genuine Android Project Generator & Remote APK Build Engine

Generates a complete, valid Android Studio Kotlin + Gradle project (`AndroidManifest.xml`, `WebViewAssetLoader`, resources, and GitHub Actions APK pipeline) or dispatches to a connected Remote Build Server.

Architectural Integrity Guarantee (Zero Fake APKs)

A standalone web browser environment does not include the multi-gigabyte native Android SDK (`aapt2`, `d8`, `apksigner`, and JDK) on-device. Therefore, HTML to APK By Piyush never fakes an APK by renaming an HTML or ZIP file to `.apk`.

• Mode 1 (Instant Local Generator — 100% Working Offline): Generates a complete, genuine Android Studio Gradle project `.zip` containing your `AndroidManifest.xml`, `MainActivity.kt`, `build.gradle.kts`, icons, all web assets under `app/src/main/assets/www/`, plus a ready-to-run GitHub Actions Free Cloud APK Workflow (`.github/workflows/build-apk.yml`) that compiles and signs a real `.apk` in the cloud for free.

• Mode 2 (Connected Remote Build Backend): Connects via HTTPS to a configured Remote Gradle Build Service API (`Settings → Remote Build Server`) to compile and return a verified binary `.apk`.

 Setup, Compilation & Deployment Documentation

          
Step-by-step instructions to compile your generated Android project into a signed `.apk` on Android (via GitHub Actions Free Cloud CI) or Desktop (Android Studio / Gradle CLI).

        


        

          

            No Computer Required • 100% Free
            
Method 1: Build APK on Android Phone via GitHub Actions

            
    
              
  1. Configure your app in App Customization Studio and click Generate & Download Android Studio Project (.ZIP).
    2. 
              
  2. Create a free repository on GitHub from your mobile browser and upload the extracted files (which already include `.github/workflows/build-apk.yml`).
    3. 
              
  3. Open the Actions tab in your GitHub repository — GitHub's cloud Ubuntu runner automatically installs JDK 17 + Android SDK 35, runs `./gradlew assembleDebug`, signs the APK, and uploads `app-debug.apk` under Artifacts for immediate download and installation on your phone!
    4. 
            

          


          

            Desktop / CLI / Self-Hosted Server
            
Method 2: Android Studio or Gradle Command Line

            
    
              
  1. Extract the downloaded `-android-studio.zip` archive.
    2. 
              
  2. Open the folder in Android Studio Ladybug (or newer), or run `./gradlew assembleDebug` from a terminal with `ANDROID_HOME` configured.
    3. 
              
  3. Your compiled APK is output to `app/build/outputs/apk/debug/app-debug.apk` and verified via `apksigner verify --verbose`.
    4.
